# Canine Wellness Screening Guidance

This document supports a synthetic diagnostic recommendation workspace for dogs.

## Common intake patterns
- Routine preventive visits with limited symptom burden should favor wellness screening rather than specialty diagnostics.
- Senior wellness visits can still justify screening even without a focused complaint.

## Common next diagnostic actions
- `WELLNESS_PANEL` is appropriate for broad preventive screening and general chemistry and CBC context.
- `HEARTWORM_4DX` is appropriate when preventive infectious screening is due.
- `FECAL_SCREEN` is appropriate when preventive stool screening is due and there is no stronger symptomatic GI workup signal.

## Relative preference notes
- Prefer preventive tests when the intake is stable and there is no high-signal symptomatic complaint.
- De-prioritize wellness-only diagnostics when an active symptomatic cohort is more strongly supported by the current intake.

## Repeat-test cautions
- Wellness screening should respect longer repeat intervals.
- If the same wellness test was done recently, explain that the action was suppressed rather than presenting it as a fresh recommendation.
